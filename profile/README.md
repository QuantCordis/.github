# QuantCordis

A 股量化研究的最小可信内核。

## 我们做什么

先修数据地基，再谈策略结论。数据层负责把行情抓下来并落库，不复权价与复权因子分开存、自己算
复权，每条记录带来源与抓取时间，完整性检查不通过就拒绝出数。回测层只回答一个问题：哪个策略
的超额为正，判据是跑赢同期买入持有，数据不过关的区间直接拒绝回测，找不到就如实报告找不到。

不做下单，不碰真实资金。

## 我们的规矩

- **判据必须能失败。** 一个不会失败的检查比没有检查更糟，因为它给人一种已经查过的错觉。
- **找不到就说找不到。** 不挑一个好看的数，不为了让曲线好看而换区间。
- **报数字带判据原文**，涉及计数写清分母与筛选条件。
- **不公开只对本机成立的东西**：用户名、家目录、令牌、硬件清单、个人邮箱。
